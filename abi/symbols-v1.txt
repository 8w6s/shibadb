# Authoritative public symbol surface of libshibadb (ABI v1).
#
# Enforced by the `abi_symbols` CTest, which compares this list against the
# dynamic symbol table of the shared library in BOTH directions: a symbol
# exported but absent here fails the build (unreviewed ABI growth), and a
# symbol listed here but no longer exported fails the build (ABI break).
# See docs/ABI.md for the compatibility policy.
#
# Rules:
#   - one symbol per line, sorted, no leading underscore (the gate strips the
#     Mach-O '_' prefix before comparing);
#   - '#' starts a comment, blank lines are ignored;
#   - additions must be append-only and backward compatible within ABI v1;
#     removals or signature changes require ABI v2 and a new SOVERSION.
#
# Groups are commented for reviewability; the gate reads the union as one set.
